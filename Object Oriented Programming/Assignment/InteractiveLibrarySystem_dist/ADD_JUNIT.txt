# Instructions
If you are using Eclipse or a similar IDE, you can add the JUnit JAR to your build path manually:
1. Download the JUnit 4.13.2 JAR from https://search.maven.org/artifact/junit/junit/4.13.2/jar
2. Right-click your project > Build Path > Add External Archives...
3. Select the downloaded JAR file and add it.

Alternatively, if you use Maven or Gradle, add the above dependency to your pom.xml or build.gradle.
