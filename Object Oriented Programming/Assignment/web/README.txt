To use images and resources from the doc folder in your web app, you can reference them with relative paths like:

<img src="../doc/script-dir/images/your-image.png" alt="...">

Or, for CSS/JS:
<link rel="stylesheet" href="../doc/stylesheet.css">
<script src="../doc/script.js"></script>

You can also copy images you want to use directly into the web/images folder for easier access.

Update your HTML as needed to include these resources.
